## 1. Summary & Fixes in v1.0.1

This patch release addresses Windows installer build configuration issues identified in GitHub Actions CI for v1.0.0:

- **MIT License Addition**: Added repository root `LICENSE` file satisfying Inno Setup installer packaging requirements.
- **Windows Inno Setup Icon & License Paths**: Fixed `packaging/windows/vaani_setup.iss` paths for `vaani.ico` and `LICENSE`, and added Start Menu/Desktop icon associations.
- **PowerShell Pip Upgrade Fix**: Corrected pip in-place upgrade syntax in `scripts/build_windows.ps1` to use `<venv>\Scripts\python.exe -m pip install --upgrade pip`.
- **Fail-Fast Build Script**: Hardened `scripts/build_windows.ps1` to exit immediately with non-zero exit codes if dependency installation, PyInstaller compilation, or Inno Setup fails.
- **Windows CI Smoke Tests**: Enhanced `.github/workflows/build-windows.yml` to install Inno Setup, compile the installer, verify artifact existence, and execute a smoke test.
- **Package Version Consistency**: Reconciled version metadata across `pyproject.toml`, Debian control files, Inno Setup, and release artifacts to `1.0.1`.
