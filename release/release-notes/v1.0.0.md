# Vaani v1.0.0 Release Notes

We are excited to announce the first stable release of Vaani!

## Overview
Vaani is a real-time Hindi/Hinglish to English voice translation and meeting takeover desktop application. It runs 100% locally to ensure privacy and low latency.

## Features
- **Real-Time Translation**: Translates Hindi and Hinglish to English instantly.
- **Local AI**: All processing happens locally on your machine.
- **Meeting Takeover**: Captures and translates audio from popular meeting applications.
- **Hardware Acceleration**: Takes advantage of NVIDIA GPUs if available for faster processing.

## Supported Platforms
- Windows 10/11 (64-bit)
- Debian/Ubuntu Linux (amd64)

## Hardware Requirements
- **CPU**: Modern multi-core processor
- **RAM**: Minimum 8GB, 16GB+ recommended
- **GPU**: NVIDIA GPU with 4GB+ VRAM recommended for optimal performance
- **Disk Space**: 5GB+ for application and local models

## Installation Instructions

### Windows
1. Download `vaani_installer.exe` from the releases page.
2. Double-click the installer and follow the setup wizard.
3. Launch Vaani from your Start Menu or Desktop.

### Debian / Ubuntu Linux
1. Download `vaani_1.0.0_amd64.deb` from the releases page.
2. Install the package using `dpkg`:
   ```bash
   sudo dpkg -i vaani_1.0.0_amd64.deb
   ```
   *Note: You may need to run `sudo apt-get install -f` if there are missing dependencies.*
3. Launch Vaani from your application menu or run `vaani gui` in the terminal.

## Known Limitations
- Background noise can degrade transcription accuracy.
- Requires initial internet connection to download open-source models on first run.

## Troubleshooting Common Issues
- **Missing Audio Devices**: Ensure PulseAudio/PipeWire is correctly configured on Linux.
- **Slow Translation**: Verify that your GPU is detected in the settings menu.

## Privacy Notice
Vaani processes all voice data locally. No audio or text is sent to cloud APIs. Your privacy is fully maintained.
