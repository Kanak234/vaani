## 1. Executive Summary

Vaani is a private, real-time Hindi/Hinglish to English voice translation and meeting takeover desktop application. It runs 100% locally with zero cloud API dependencies, zero telemetry, and zero data exfiltration.

The software automatically discovers host hardware capabilities, assigns a tailored execution profile (`LOW`, `BALANCED`, `HIGH`), verifies runtime inference health (including Ollama GPU probing with automated AVX2 CPU fallback), and bridges voice audio seamlessly into Zoom, Google Meet, and Microsoft Teams.

---

## 2. Core Features & Capabilities

- **Real-Time Hindi/Hinglish Voice Translation**: Real-time STT (Whisper), translation routing (NLLB-200 / local Ollama LLM for colloquial Hinglish), and neural TTS (XTTS-v2 or formant fallback).
- **Meeting Takeover**: Monitors remote incoming meeting questions, tracks hesitation signals ("um", "uh"), detects prolonged silence (>4.0s or extended >8.0s), and can automatically or explicitly ("Vaani, take over") draft and speak answers via virtual microphone.
- **Hardware Auto-Detection**: Probes CPU instruction sets (AVX2, AVX512), RAM capacity, NVIDIA GPUs, VRAM, CTranslate2 CUDA backends, and audio endpoints.
- **Safe GPU Probing & CPU Fallback**: Automatically tests GPU Ollama inference; on llama-server status `0xc0000005` errors, automatically pivots to a private AVX2 CPU worker on port 11435 without crashing or killing unrelated processes.
- **Dynamic Vision Screen Analysis**: Samples screen recording frames locally and queries available Ollama vision models (e.g. `qwen2.5-vl:3b`, `llava`, `moondream`) to draft informed meeting answers.
- **5-Tab Desktop GUI**: Provides System Dashboard, Meeting Mode, Screen Analysis, Settings, and Diagnostics with asynchronous event queues and instant Emergency Stop (`Esc` / `Ctrl+Shift+S`).
- **Cryptographically Hashed Voice Consent**: Enforces explicit affirmation and durable append-only logging before personal voice cloning is permitted.

## 5. Installation Instructions

### Windows (10/11 x64)
1. Install [VB-Audio Virtual Cable](https://vb-audio.com/Cable/) and [Ollama](https://ollama.com).
2. Download and run `vaani_installer.exe` or execute `vaani.bat gui` from source.
3. In Zoom/Meet/Teams, select **"CABLE Output (VB-Audio Virtual Cable)"** as the microphone.

### Debian / Ubuntu Linux (amd64)
1. Download `vaani_1.0.0_amd64.deb`.
2. Install via dpkg:
   ```bash
   sudo dpkg -i vaani_1.0.0_amd64.deb
   ```
3. Launch from the desktop applications menu or run `vaani gui` in a terminal.
4. In Zoom/Meet/Teams, select **"Vaani Virtual Microphone"**.
